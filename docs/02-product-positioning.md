# Product Positioning

## 项目定位

Mystery Agent Lab 是：

AI 推理游戏引擎

不是：

- 多人平台
- Web 产品
- CMS 系统

## 为什么选择剧本杀

剧本杀天然覆盖：

- Agent Response
- Memory
- Tool Calling
- Guardrail
- Retrieval
- Context Engineering
- Runtime

能够暴露真实 Agent 问题。

## 当前重点

验证：

1. AI 推理体验是否成立
2. NPC 是否可信
3. 调查机制是否有效

而不是：

- 架构炫技
- 功能堆叠
- 平台化扩张

## 风险控制

每次新增功能前检查：

- 是否增加 NPC 泄底风险
- 是否导致上下文膨胀
- 是否让 GameState 臃肿
- 是否增加 Prompt 复杂度
- 是否扩大项目范围

优先解决真实游玩中暴露的问题。
