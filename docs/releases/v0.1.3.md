# Release Plan - V0.1.3

## 版本主题

会话记录与调查轮复盘增强

## 目标

增强复盘能力，稳定调查轮记录。

## 开发范围

- SessionRecorder 纳入 history
- SessionRecorder 纳入 rounds
- Markdown 按调查轮展示
- review 轻量优化
- 回归测试

## 明确禁止

- GameSession
- GameEvent
- InvestigationResult
- hidden clue
- suspect state
- AI 总结

## 验收标准

- history 可完整导出
- rounds 可完整导出
- Markdown 按调查轮展示
- review 输出正确
- 回归测试通过

## 完成定义

用户可以通过导出的 Markdown 复盘完整调查过程。
