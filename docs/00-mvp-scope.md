# AI 在线剧本杀 MVP 范围

## 1. 项目目标

本项目的目标是实现一个「单人文本版 AI 在线剧本杀」最小闭环。

玩家通过文字与系统互动，完成一局简化版剧本杀游戏，包括：

- 查看案件背景
- 询问 NPC
- 搜索线索
- 整理推理
- 提交最终答案
- 查看真相复盘

第一版不追求复杂剧情、不追求多人在线、不追求精美前端，而是优先验证：

- AI 是否能稳定扮演角色
- 游戏状态是否能正确推进
- 线索是否能按阶段解锁
- NPC 是否能避免泄露不该知道的信息
- 玩家是否能完成从开局到结局的完整流程

---

## 2. 第一版核心定位

第一版不是完整商业产品，而是 Agent 学习项目。

它重点验证以下 Agent 能力：

| 能力 | 在本项目中的体现 |
|---|---|
| 角色扮演 | NPC 按角色身份回答玩家问题 |
| 工具调用 | 查询线索、记录提问、提交投票 |
| 状态管理 | 记录当前阶段、已解锁线索、已提问内容 |
| 记忆管理 | 记录玩家行为和 NPC 已暴露信息 |
| 规则约束 | 防止 NPC 越权回答、提前泄露真相 |
| 结构化输出 | Judge 返回明确的合法性判断 |
| 流程编排 | Host 推动游戏阶段变化 |
