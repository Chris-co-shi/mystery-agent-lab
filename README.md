# Mystery Agent Lab

> AI 推理游戏引擎（AI Detective Game Engine）

通过构建 AI 剧本杀项目，学习 Agent Architecture、Memory、Tool Calling、Guardrail、Context Engineering 与 Runtime Design。

## 项目简介

Mystery Agent Lab 是一个 Agent 学习项目。

项目目标不是快速做成平台，而是通过真实的推理游戏场景，逐步理解 Agent 系统在实际业务中的设计问题与演化过程。

## 当前状态
